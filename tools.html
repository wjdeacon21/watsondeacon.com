NYC Concert Calendar

Sign in with Spotify to see upcoming concerts by any artist you've added to your Liked Songs. Note: Spotify recently limited permissions for individual developers using their API, so you now need to be added to an allowlist to use this. Let me know if you're interested!

Customer FAQ Email Automation

This is a prototype I made for a friend who runs a pop-up village I attended in Argentina in 2025. It lets the user respond more quickly to FAQs received via email by automatically ingesting all messages to a specific address and referencing a library of blog posts and web pages in which important info about the event is recorded.
